## Project Description

This capstone project focuses on developing and deploying a Customer Accounts Microservice using modern DevOps practices.

The application provides RESTful APIs to create, retrieve, update, delete, and list customer accounts.

The project demonstrates software development, automated testing, Continuous Integration, security implementation, containerization, and Continuous Deployment.

## Technologies Used

- Python and Flask
- RESTful APIs
- Git and GitHub
- GitHub Actions
- Docker
- Kubernetes
- Tekton
